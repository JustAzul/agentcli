# Documentation

The requirements of `msgate-agents` are group H of [`split-PRD.md`](split-PRD.md)
(the agent types, their profiles, the engine check and the dispatch skill), and
group K for the hidden rows of phase 3. [`split-test-cases.md`](split-test-cases.md)
holds the matching test cases.

The engine this plugin uses, `msgate`, lives in
[`JustAzul/cc-msgate`](https://github.com/JustAzul/cc-msgate), with its
documentation: the requirements, frame and test cases of the project as it was
called `agentcli`, which describe the engine, and the groups of the split
requirements that concern it.
